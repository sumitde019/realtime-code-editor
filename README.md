# 📝 Real-Time Code Editor

A collaborative, real-time code editor built using **WebSocket**, **HTML**, **CSS**, and **JavaScript**. It allows multiple users to write and edit code simultaneously with instant synchronization.

## 🚀 Features

- 🔄 Real-time code synchronization via WebSocket
- 🖥️ Live editing interface with HTML/CSS/JS
- 👥 Multi-user collaboration
- 📦 Lightweight and fast

## 🛠️ Technologies Used

- HTML, CSS, JavaScript (Frontend)
- WebSocket (Real-time communication)
- Node.js + `ws` (for WebSocket server)
